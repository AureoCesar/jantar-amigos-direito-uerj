# Jantar dos Amigos Direito UERJ — Orçamento

Dashboard privado para acompanhamento e simulação do orçamento anual.

## Publicação

Este repositório é intencionalmente privado. O painel deve ser publicado apenas por uma hospedagem com controle de acesso no servidor, nunca por GitHub Pages com senha em JavaScript.

## Dados

`index.html` contém a base orçamentária recebida e permite simulação local por dispositivo. Não publicar em um serviço sem autenticação real.
